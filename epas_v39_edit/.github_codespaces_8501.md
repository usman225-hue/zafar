# EPAS Demo on GitHub Codespaces — Port 8501

EPAS is not hosted by GitHub Pages. For a live demo on GitHub, use **GitHub Codespaces** or another host that can expose a Streamlit port.

## Start demo

```bash
cd epas_v39_edit
./scripts/run_demo_8501.sh
```

Then open the forwarded **8501** port in Codespaces.

## Promote to professional production

Create a clean production copy with demo-only files removed:

```bash
python scripts/strip_demo_for_production.py --output ../epas-production
cd ../epas-production
./scripts/run_production_8501.sh
```

The production copy requires:

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

and uses Supabase Auth only.
