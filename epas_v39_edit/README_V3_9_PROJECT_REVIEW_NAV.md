# EPAS v3.9 — Project Review Navigation

Project-specific navigation now includes:

1. Project Overview
2. Plan Appraisal (when in scope)
3. NSC Survey (when in scope)
4. In-Service Survey (when in scope)
5. Survey Status (review-only)
6. Risk Register
7. Ship Register (review-only)
8. Certification
9. Documents
10. Notifications
11. Audit Trail

The selected project remains the primary context. Survey Status and Ship Register are read-only review surfaces whose values are sourced from current project/vessel/certificate activity.

The Project Overview intentionally excludes Workflow Snapshot and Recent Activity. The role cockpit also no longer renders those sections; it uses Project Health, Priority Queue, Next Actions, Milestones, Upcoming Deadlines and Certificates Overview instead.
