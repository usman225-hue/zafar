# EPAS v4.0 — Project-Centric Role Workspace

The project workspace now follows the approved PSB reference interaction:

1. Global navigation is used to enter Projects.
2. GM alone has the Create Project action, located only in the Projects register.
3. Selecting a project replaces the global sidebar with project-specific navigation.
4. Project navigation includes only the phases included in that project plus Survey Status, Risk Register, Ship Register, Certification, Documents, Notifications and Audit Trail.
5. Project Overview intentionally excludes Workflow Snapshot and Recent Activity.
6. Survey Status and Ship Register are review-oriented project views and remain controlled by the authenticated role and backend security.
