# EPAS v1.5 — Critical Gap Closure

This release closes the critical gaps identified against the supplied GM/DM flowcharts.

## Closed in v1.5

1. **Controlled stakeholder document release**
   - GM/DM release only approved controlled documents.
   - Release audience is explicit: Designer, Owner, Ship Management, Shipyard.
   - Owner and Shipyard remain read-only.
   - Release and withdrawal are auditable.
   - Stakeholder downloads use signed URLs and create access-audit records.

2. **Plan appraisal technical record**
   - Engineer observations store rule/clause and drawing references.
   - DM/GM closure notes are controlled.
   - Designer revision carries parent revision, correction task and latest management decision trace.

3. **Survey observation lifecycle**
   - Survey reports include evidence, attendance, declaration and location.
   - Survey observations store rule reference, deficiency category, responsible party, target date and corrective action.
   - DM/GM closure is explicit and auditable.

4. **Corrective evidence integrity**
   - Evidence path is controlled by project/action.
   - SHA-256, MIME and file size are stored.
   - Evidence submission creates DM verification task.

5. **Interim -> Full Certificate**
   - Final certificate cannot be issued while survey observations remain open.
   - Interim certificate is superseded and linked to the final certificate.
   - Certificate lifecycle events are persisted.

6. **Working-day SLA**
   - SLA policies are configurable per workflow task type.
   - Due dates are generated from business days when not explicitly supplied.
   - Warning and overdue notifications are generated by the scheduler RPC.

7. **Resource conflict**
   - Engineer and Surveyor eligibility checks now include authorization, competency, availability, workload and overlapping task windows.
   - DM sees open, overdue, due-soon, overlapping assignments and utilization/capacity.

8. **GM escalation actions**
   - GM can acknowledge, return, reject or assign a real action owner and due date.
   - Assigned action is linked to a workflow task.

9. **Project closure**
   - Closure checks verify drawings, observations, tasks, corrective actions, escalations, milestones and certificate state.
   - Successful GM closure creates an archive record.

10. **Audit/security**
    - Critical browser writes are revoked.
    - Workflow mutations use SECURITY DEFINER RPCs.
    - Document view/download/release/withdraw events are auditable.
    - Notification email is queued for controlled workflow events.
