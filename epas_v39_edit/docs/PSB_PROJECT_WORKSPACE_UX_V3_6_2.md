# PSB EPAS v3.6.2 — Project-Specific Workspace UX

## Behavior
Selecting **Open project →** no longer leaves the user in a generic role page.

The selected project becomes the primary context and opens a dedicated project workspace:
- project identity/header remains visible
- completion / overdue / escalation / health status remain visible
- left-side navigation becomes role-specific
- only project-authorized information/actions are shown
- Back to Projects returns to the role project register

## Role-specific left navigation

GM:
Overview, Project Information, Plan Appraisal, Survey/RFI, Certificates, Milestones, Observations, Documents, Governance, Audit Trail

DM:
Overview, My Work, Plan Allocation, Survey/RFI, Resources & SLA, Corrective Actions, Observations, Documents, Coordination

Engineer:
Overview, My Assignments, Plan Appraisal, Observations, Documents, History
