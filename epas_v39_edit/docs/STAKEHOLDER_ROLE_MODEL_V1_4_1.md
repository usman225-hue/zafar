# EPAS External Stakeholder Role Model v1.4.1

## Internal classification roles
- GM Classification
- Department Manager
- Authorized Engineer
- Authorized Surveyor

## External stakeholder roles
- Designer
- Ship Management
- Owner
- Shipyard

## Execution boundary
### Designer
External stakeholder with controlled execution rights only for:
- initial drawing submission
- assigned drawing correction/revision

### Ship Management
External stakeholder with controlled execution rights only for:
- assigned corrective-action tasks
- evidence submission

### Owner
Read-only stakeholder:
- released project information
- released milestones
- released certificates
- released documents
- stakeholder notifications

### Shipyard
Read-only stakeholder:
- released project information
- released milestones
- released certificates
- released documents
- stakeholder notifications

External stakeholder status does NOT grant internal classification privileges, engineering authorization,
survey authorization, project management rights, or unrestricted project/document visibility.
