# EPAS v3.5 Role Workflow Audit

## GM
Project definition → Plan/Appraisal governance → RFI intake → Survey decisions → Certificate decision → Closure.

## DM
Allocation → Engineer/Surveyor eligibility → Scope → Drawing handover → Survey readiness → Corrective-action verification → Certificate acknowledgement.

## Engineer
Assignment → Technical appraisal → Marked-up drawing/report → Decision → optional Surveyor verification → Manager review.

## Surveyor
Assignment → Acceptance → Scope acknowledgement → Drawing package acknowledgement → Pre-survey checklist → Revision-impact gate → Execution → Professional declaration → Report → Observations.

## Designer
Submission → Review → Correction → Revision → Resubmission → Approval/release.

## Shipyard
NSC RFI only → NSC status → relevant approved drawing/release information → NSC survey lifecycle.

## Owner
In-Service RFI only → Fleet/Schedule visibility → Next survey → Certificate/status visibility → released stakeholder actions.

## Ship Management
In-Service RFI only → In-Service scheduling → assigned corrective actions → evidence → verification → next survey cycle.

## Project phase sequencing
Plan-only ends after Plan completion. Plan+NSC continues into NSC then ends after NSC completion. Plan+NSC+In-Service keeps In-Service ACTIVE and creates recurring survey cycles.
