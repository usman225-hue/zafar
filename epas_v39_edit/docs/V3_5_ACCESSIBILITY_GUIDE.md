# EPAS v3.5 Accessibility Baseline

- Visible keyboard focus is enforced on controls.
- Reduced-motion users receive non-animated transitions.
- Responsive breakpoints support desktop/tablet/narrow screens.
- Status information is rendered with text as well as semantic color.
- High-impact actions use explicit labels and confirmation patterns in the workflow components.

## Final deployment acceptance
The production team should complete a WCAG 2.1 AA browser pass covering keyboard-only navigation, focus order, zoom to 200%, screen-reader labeling, data-table navigation and error-message clarity.
